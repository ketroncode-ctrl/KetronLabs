Autonomous Execution

Inside Pilot Mode

Ketron Code Editor's Pilot Mode is an AI coding agent powered by the Gemini API. It operates in an autonomous agentic loop — analyzing your project, writing code, running it locally, and self-correcting until your goal is achieved. An active internet connection is required to use Pilot Mode.

Phase 01 — Write & Edit

Understands Your Codebase

Tell Pilot your goal in plain English. It reads your project files, understands the module graph, and writes precise multi-file changes — never hallucinating unknown APIs or packages.

# Goal set:
"Add a REST endpoint for user login"
# Writing: auth.py, routes.py updated...
Phase 02 — Analyze & Plan

Maps Your Entire Project

Before writing a single line, Pilot reads every relevant file in your workspace, maps module dependencies, and builds a step-by-step implementation plan — so changes are always coherent and complete.

# Reading: main.py, models.py, utils.py
[Plan] Step 1 → create auth.py
[Plan] Step 2 → patch routes.py:L48
Phase 03 — Test & Self-Debug

Fixes Its Own Mistakes

If tests fail or exceptions are thrown, Pilot reads the full traceback, pinpoints the root cause, and surgically patches the code — looping autonomously until every assertion passes.

✗ AssertionError at test_auth.py:38
# Tracing bug. Applying fix...
✓ All 22 assertions passed.
